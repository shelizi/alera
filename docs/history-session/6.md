## 用户核心目标

- Fix Alera on Windows so right-clicking a file and choosing the file-manager action opens the correct directory; folders already worked correctly.

## 已确认事实

- The existing main branch already used explorer.exe with a single /select,<path> argument for files, while directories were opened directly.
- Alera's Rust-backed ProcessRunner routes Windows commands through cmd.exe and quotes each argument. Explorer can return exit code 0 while ignoring a quoted /select,<path> target, which explains why unit tests passed but the real UI opened the wrong/default location.
- The direct explorer.exe folder-opening path is already reliable, matching the user's observation that directories open correctly.

## 已完成修改

- lib/src/features/workbench/application/workspace_folder_opener.dart
- test/unit/workspace_folder_opener_test.dart

## 关键设计决定

- On Windows, file reveal now opens the file's containing directory directly instead of relying on Explorer's /select switch through the shell wrapper.
- macOS and Linux reveal behavior remains unchanged.
- Use package:path p.windows.dirname after existing Windows path normalization so drive roots, spaces, forward slashes, and extended-length paths are handled consistently.
