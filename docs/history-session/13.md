## 已确认事实

- WorkspaceEditorSurface 使用 code_forge.CodeForge，並傳入自訂 scrollbarDecoration。
- _scrollbarDecoration() 明確設定 thickness: 0、thumbColor: Colors.transparent、trackVisibility: false、track/trackBorder 皆透明，因此目前 scrollbar 是刻意隱藏，而非單純未觸發顯示。
- 編輯器同時設定 lineWrap: true，因此一般不依賴 X 軸水平捲動。
- Alera intentionally hid the CodeForge vertical scrollbar with thickness 0 and transparent thumb.
- Alera uses code_forge 10.13.0. The installed package already computes first/last visible lines, prunes viewport caches, and pre-highlights only viewport-adjacent lines, so document-level chunk/lazy loading would duplicate existing virtualization and risk breaking whole-document editing/search/save semantics.
- Long-file hot paths include forced lineWrap and indentation guide work. CodeForge has extra wrapped-height/paragraph layout work when wrapping is enabled; guide calculation scans around the visible range.
- Windows has no Alera setting forcing software rendering. docs/performance.md says Windows retains Flutter SDK renderer defaults; the lag is therefore more consistent with CPU text layout/highlighting/FFI/paint costs than an intentionally disabled GPU renderer.
- main had unrelated pre-existing Rust/generated file modifications and untracked worktree/history/release files; these were preserved.
- feat/editor-scroll-performance contained commit c3b43b62 perf(editor): improve long-file scrolling.
- Merge completed cleanly with ort and no conflicts.
