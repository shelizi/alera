## 已确认事实

- Alera TerminalView uses xterm.clipboardTerminalShortcuts and shiftOverridesMouseReporting=true.
- Current clipboard shortcuts include Ctrl+Shift+C copy on Windows/Linux, Ctrl+Shift+V paste, and select-all shortcut; there is no Shift+Arrow selection-extension shortcut.
- Shift currently bypasses terminal mouse reporting so local mouse drag selection remains available even when a TUI captures mouse input.
- Mouse drag starts a fresh character/line selection; Alt+drag selects block mode. No Shift+click logic extends an existing selection.
- Alera's terminal uses the vendored third_party/xterm TerminalView, so the behavior was implemented in the xterm selection path rather than intercepted in Alera presentation code.
- Shift+click now preserves the existing selection anchor and moves the selection extent to the clicked cell.
- The extension only runs when the terminal application does not own the Shift+mouse event; existing mouse-reporting/XTSHIFTESCAPE behavior remains intact.
- Normal non-Shift click still clears an existing selection as before.
- CodeForge already supports Shift keyboard selection across arrows, Home/End, document Home/End, and word movement using TextSelection.baseOffset/extentOffset.
- The missing behavior was desktop mouse Shift selection: normal pointer down always collapsed selection at the clicked offset and reset the drag anchor.
- Implemented Shift+click using the existing TextSelection anchor model: preserve selection.baseOffset and move extentOffset to the clicked offset.
- Shift+drag now continues from the same preserved baseOffset because _dragStartOffset is set to the existing selection anchor.
- Collapsed caret + Shift+click extends from the caret; forward and reverse selections preserve their original anchor.
- Alt-click remains higher priority for multi-cursor behavior. Shift mouse selection clears secondary cursors, matching existing Shift keyboard selection semantics.
- Mobile selection/handles, IME composition, ordinary click, double-click word selection, and existing keyboard selection logic were not changed.
