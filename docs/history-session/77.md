## 用户核心目标

- 釐清 Alera 手機版如何連線、是否需要雲端伺服器，並對照 Orca Mobile。

## 已确认事实

- Alera 獨立 Flutter mobile/ 應用透過 runtime-host mobile WebSocket gateway 連線，QR pairing 並安全儲存 device token。
- desktop GUI 可以關閉，但 alera runtime start 啟動的獨立 Rust runtime 必須保持運作。
- Gateway 支援 This Device (loopback)、Tailscale、NetBird、Manual TLS proxy；不需自行架雲端伺服器即可透過 Tailscale/NetBird 跨網路操作。
- docs/remote-access-relay.md 描述 Cloudflare Durable Objects relay 作為 direct LAN/VPN transport 失敗後的選用備援，120 秒 grant 與端對端加密；需 Alera cloud/edge 部署以及登入，功能預設 opt-in off。
- cloud/readme.md 說明 API 驗證、mobile enrollment、push 訂閱/FCM、relay grants；推播與雲端功能需 production OAuth/Cloud/Firebase 設定並真機驗證。
- Orca 官方 docs 的 mobile 為 React Native/Expo，桌面 Electron 提供 port 6768 WebSocket RPC，支援 LAN 或自家 relay；relay 模式下雙方 outbound WebSocket，另有 push gateway。
