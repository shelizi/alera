## 用户核心目标

- Implement two Alera features: add a file context-menu action to open files with the operating system default application, and add project-level sleep that sleeps all workspaces/worktrees under the project.

## 已确认事实

- Workspace Explorer already had a cross-platform WorkspaceFolderOpener/reveal path and external-editor context menu, so the default-app action was added alongside those existing flows.
- Workspace sleep semantics already close terminal runtime, editor sessions, tabs, and layout while preserving files/branches/worktrees; project sleep reuses this existing controller path for every workspace in the project.
- On Windows the default-app action uses rundll32.exe url.dll,FileProtocolHandler with normalized paths; macOS uses open; Linux uses xdg-open with gio fallback.
