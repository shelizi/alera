## 用户核心目标

- Fix Alera Terminal on Windows where the main Enter key was ignored while numpad Enter worked.

## 已确认事实

- Alera shortcut resolution does not bind bare Enter; PTY/xterm core emits carriage return correctly.
- The failing path is Windows IME composition: CustomTextEdit swallowed main Enter while composing, then committed text arrived later without replaying the swallowed Enter.
- A red regression test reproduced the failure as terminal output containing committed text but no carriage return.

## 已完成修改

- third_party/xterm/lib/src/ui/custom_text_edit.dart
- third_party/xterm/test/src/terminal_view_test.dart
- third_party/xterm submodule pointer in Alera

## 关键设计决定

- Keep Windows text-input composition enabled; do not revert hardwareKeyboardOnly=false.
- Queue only Windows main Enter key-down while composition is active and replay it after the composition commits.
