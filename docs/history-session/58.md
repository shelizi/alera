- Add syntax highlighting to all Alera Git diff displays, including editable and read-only modes.

## 已确认事实

- The existing workspace editor already centralizes syntax language resolution and CodeForge highlighting and can be shared safely.

## 关键设计决定

- Reuse the main editor's language resolver and CodeForge SyntaxHighlighter instead of creating a separate diff grammar mapping.
- Keep diff additions/deletions as background and marker overlays while syntax tokens own code foreground colors.
- Use a syntax-aware TextEditingController for editable/read-only TextField panes; preserve IME composition by falling back to the base composing span while composition is active.
- Scope cached syntax highlighters per file/language/theme across lazy diff rows.
