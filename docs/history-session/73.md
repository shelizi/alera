- Make Alera completion system notifications clickable so selecting one restores/focuses Alera and opens the corresponding workspace/tab.

- Notification payloads already carried workspaceId, tabId, and terminalSessionId, and running-app activation already selected the target tab.
- The missing case was notification cold-start: flutter_local_notifications launch details were not consumed, and activation could occur before Workbench bootstrap.
- Before this change, notification activation itself was only covered with Codex. Other notification tests covered some but not all agent types.
- Current AgentType values are codex, claude, copilot, cursor, agy, opencode, opencode2, pi, amp, grok, devin, fx.
